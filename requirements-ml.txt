# Тяжёлый ML-стек для forced alignment и диаризации.
# ВАЖНО: ставится ТОЛЬКО на Python 3.12 (venv), НЕ на 3.13/3.14 —
# ctranslate2/faster-whisper пока не собирают колёса под 3.13+.
#
#   python3.12 -m venv .venv-ml
#   . .venv-ml/bin/activate
#   pip install -r requirements-ml.txt
#
# После установки основной пайплайн (app.py) сам подхватит whisperx и
# pyannote.audio через soft-import. Для pyannote нужен HF_TOKEN и принятие
# условий модели на huggingface.co.

torch>=2.2,<3
# Начиная с torchaudio 2.9 убрали torchaudio.AudioMetaData/list_audio_backends
# (deprecated в 2.8, удалены в 2.9 — переход torchaudio на TorchCodec), а
# pyannote.audio 3.x на них опирается -> "module 'torchaudio' has no
# attribute 'AudioMetaData'". НЕ понижаем версию здесь: у torchaudio жёсткая
# ABI-привязка к конкретной версии torch, и старая версия может не найти
# совместимую сборку под новый torch (риск ABI-краша хуже самой ошибки).
# Вместо этого app.py содержит runtime-заглушку
# (_patch_torchaudio_audiometadata_compat), которая восстанавливает
# отсутствующие атрибуты перед импортом pyannote.audio.
torchaudio>=2.2,<3
# БЕЗ жёсткого ==1.0.0: та версия тянет av==11.0.0 (2023 год) — под свежий
# FFmpeg (8.x из Homebrew) для неё нет готовой сборки, pip собирает av из
# исходников и падает на переименованном API (AV_OPT_TYPE_CHANNEL_LAYOUT ->
# AV_OPT_TYPE_CHLAYOUT). Свежий faster-whisper тянет свежий av с готовой
# сборкой (со своим ffmpeg внутри) — собирать из исходников не нужно вовсе.
faster-whisper>=1.0
whisperx>=3.1,<3.4
pyannote.audio>=3.1,<4
# Сепарация вокала перед выравниванием — вытягивает P90 онсета на музыке:
demucs>=4.0
# Альтернатива whisperx для выравнивания (turnkey, романизация из коробки):
ctc-forced-aligner
